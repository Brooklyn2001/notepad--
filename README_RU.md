## О проекте

Notepad-- — это легкий текстовый редактор, поддерживающий платформы Windows, Linux и Mac.

Цель разработки — создание отечественной (китайской) альтернативы текстовым редакторам, с акцентом на развитие под национальную операционную систему Uos, macOS и различные дистрибутивы Linux.

По сравнению с другими аналогичными программами (конкурентами Notepad), главное преимущество `ndd` (Notepad--) — кроссплатформенность и поддержка Linux и macOS.

**В связи с некорректными высказываниями авторов некоторых конкурирующих редакторов, смысл Notepad-- заключается в следующем: немного меньше ошибочных заявлений, немного меньше самоуверенности.**

**Цель Notepad-- — создание альтернативы для отечественного ПО, с фокусом исключительно на разработке программного обеспечения.**

Вы можете сообщать об ошибках или оставлять отзывы в этом проекте.

Этот репозиторий и [https://gitee.com/cxasm/notepad--](https://gitee.com/cxasm/notepad--) — одно и то же программное обеспечение. В Китае используется Gitee. За пределами Китая используется этот репозиторий на GitHub, который периодически синхронизируется с Gitee. Поскольку у автора в Китае часто нет доступа к GitHub, этот репозиторий может обновляться с задержкой. Приносим извинения за неудобства.

Ссылка для скачивания последней версии: [https://gitee.com/cxasm/notepad--/releases/tag/v3.5](https://gitee.com/cxasm/notepad--/releases/tag/v3.5)

**В связи с тем, что Notepad-- подвергся анонимной критике со стороны конкурентов, проект ndd заявляет:**

**Notepad-- не имеет отношения к политике и тем более не будет публиковать политические заявления.**
